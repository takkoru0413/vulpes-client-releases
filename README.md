# Vulpes Client

All-in-one PvP client for Minecraft Java Edition, with its own launcher.

## Download

Get the latest **`Vulpes Client-x.y.z.exe`** from the [Releases](https://github.com/takkoru0413/vulpes-client-releases/releases/latest) page and run it.

- No administrator rights needed, no Java install needed.
- The launcher tells you when a new version is available and can update itself.

## Features

- 77 mods in one menu (Right Shift in game): HUD, combat, visual and utility mods
- Always-on performance pack: Sodium, Lithium, FerriteCore, EntityCulling, ImmediatelyFast
- Play Vulpes Client on the latest versions, or any vanilla version back to 1.5
- Add more mods from Modrinth inside the launcher
- Keybinds, FOV, server list and mod settings are shared between versions
